# Documentación

La referencia de trabajo es floryacy. Leer primero [CONTRIBUTING](../CONTRIBUTING.md).
El código y `config/split_extension_este.json` definen el comportamiento vigente.

| Necesidad | Documento |
|---|---|
| Localizar código, entradas y contratos | [Mapa del código](../src/INDICE.md) |
| Pasos para correr el flujo, preparar/verificar datos y entrenar | [Multicampaña](guias/multicampana.md) |
| Preparar y evaluar TEST 20HNJ/20HNH | [TEST vigente](guias/test_actual.md) |
| Interpretar códigos de las etiquetas | [Leyenda MNC](referencias/leyenda_mnc.md) |
| Consultar decisiones, fallos y resultados anteriores | [Archivo histórico](historico/README.md) |

`guias/` contiene procedimientos actuales, sin PID ni estados de lanzamientos.
`referencias/` contiene definiciones científicas. `historico/` conserva registros
fechados: sus comandos, splits y rutas describen aquella ejecución.
Para resultados y ubicaciones físicas, consultar [artifacts](../artifacts/README.md).

Actualizar la guía existente antes de crear otra. Una corrida se documenta en
sus metadatos externos; incorporar al historial del repo solo decisiones que
expliquen cambios de método o almacenamiento. Evitar copias locales de la misma guía.
