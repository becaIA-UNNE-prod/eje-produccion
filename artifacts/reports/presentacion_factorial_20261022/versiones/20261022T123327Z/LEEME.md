# Empezar acá

1. Abrir [PRESENTACION.html](PRESENTACION.html). Contiene el relato, los gráficos y un modo de exposición. Funciona sin internet.
2. Ensayar con [GUION.md](GUION.md). Cada página incluye también notas desplegables.
3. Consultar el anexo técnico desde la última página, sin mezclarlo con el relato principal.

La presentación HTML es editable con un editor de texto y regenerable mediante scripts/diagnostico/presentar_factorial.py. No se exportó PPTX porque el runtime requerido por la habilidad de presentaciones no está disponible en esta sesión. La opción de impresión del navegador permite guardar una versión PDF.
